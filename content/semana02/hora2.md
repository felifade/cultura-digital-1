# Hora 2: Conozco el teclado antes de trabajar

**Propósito:** Identificar las teclas principales y usar combinaciones básicas para escribir datos escolares sin errores.

<section class="momento momento-inicio">
<h2>Inicio: el teclado es una herramienta de precisión</h2>
<p><strong>Tiempo sugerido:</strong> 10 minutos.</p>
<p>Un error en una letra, punto, arroba o mayúscula puede impedir que ingreses a tu cuenta.</p>
</section>

## Teclas principales

| Tecla | Uso básico |
| --- | --- |
| Letras y números | Escribir usuario, contraseña y textos. |
| Barra espaciadora | Separar palabras. |
| Enter | Aceptar, bajar línea o enviar una instrucción. |
| Shift | Mayúsculas temporales y símbolos. |
| Bloq Mayús | Mantener mayúsculas activas. |
| Retroceso / Backspace | Borrar hacia atrás. |
| Suprimir | Borrar hacia adelante, si existe. |
| Tab | Avanzar entre campos. |
| Ctrl | Combinar atajos. |
| Alt Gr | Escribir símbolos especiales como @. |

## Símbolos prioritarios

- **@** para correos.
- **.** para dominios y archivos.
- **_** guion bajo.
- **-** guion medio.
- **/** diagonal.
- **?** signo de pregunta.

## Atajos útiles

| Atajo | Acción |
| --- | --- |
| Ctrl + C | Copiar |
| Ctrl + V | Pegar |
| Ctrl + Z | Deshacer |
| Ctrl + S | Guardar, cuando aplica |

## Producto en libreta: Mapa rápido del teclado

Debe incluir:

- Dibujo o esquema simple de un teclado.
- Al menos 10 teclas importantes señaladas.
- Dos formas de obtener el arroba.
- Cuatro atajos útiles.
- Respuesta: **¿por qué escribir bien el correo y la contraseña evita problemas?**
